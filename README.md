## Lab 1: Requirements Engineering

Requirements analysis for the Virtual Technical Conference Platform. Includes a requirements table with five functional and two nonfunctional requirements, a UML use case diagram for the Participant, Speaker and Organizer actors, and a use case flow document for Enroll in Session with its main and alternate flows.

## Lab 2: Agile Planning with Jira

Agile planning for the platform using Jira. Includes the product backlog with epics and user stories, story point assignments, the active sprint board, burndown charts for two sprints, and answers to the reflection questions.

## Lab 3: Component Modelling and Architectural Pattern Selection

Architecture design for the platform using a Microservices Architecture. Includes the identified components, a UML component diagram, the interfaces between components, and a justification of the chosen architecture covering scalability, fault isolation, security and performance.

## Lab 4: AI Assisted Development

Bug fixing and feature development on the Rhythm Tap game. Fixed HUD clipping, the difficulty ramp and the hit window, and added hit sounds, hold notes, BPM synced note spawning and a grade summary screen. Includes gameplay videos from before and after the changes, a PDF with the link to the AI chat used, and the full project code.

Original repository: https://github.com/sahanaks1011/51_rhythm-tap_cs425

## Lab 5: Static Code Analysis

Static analysis of a flight reservation system using Pylint, Flake8 and Bandit. All reported issues and two logic bugs were fixed, raising the Pylint score from 4.00/10 to 10.00/10 and reducing the Flake8 and Bandit issues to zero. Includes the fixed code, issues.md, reflection.md, the tool reports from before and after the fixes, and a PDF of the tool outputs.

Original repository: https://github.com/sahanaks1011/L5_50_flight_reservation_system
